# CaseClash — демо кейсов и батлов

Демо-платформа открытия кейсов CS2, кейс-батлов, апгрейдов и контрактов **на выдуманных монетах**.

- 🪙 только демо-монеты: стартовый баланс, ежедневный бонус, промокоды;
- ❌ нет депозитов, выводов, обмена на реальные деньги или предметы;
- 🎲 честные шансы (provably fair) — выиграть и проиграть можно по-настоящему.

## Что есть

| Раздел | Возможности |
|---|---|
| Кейсы | ~165 кейсов по категориям (стартовые, цвета, премиум, «X для всех», ножевые, перчаточные, тематические, праздничные, кино и игры, лимитированные, официальные кейсы CS2), поиск и сортировка, открытие x1–x5, быстрый и медленный режим рулетки, продажа выпавшего |
| Скины | ~2100 реальных скинов CS2 (576 ножей, 94 перчатки) из открытого датасета, картинки со Steam CDN, демо-цены по редкости |
| Апгрейд | до 6 предметов + добавка балансом, кнопки x2/x5/x10 и 30/50/75%, шанс = ставка/цель × 0,95 (макс. 80%), колесо с честным броском |
| Контракты | 3–10 предметов → один предмет стоимостью 25–300% суммы |
| Кейс-батлы | 1v1, 1v1v1, 1v1v1v1, 2v2, «безумный» режим, боты, live через WebSocket, победитель забирает всё |
| Профиль | инвентарь, продажа, история, статистика, лучший дроп |
| Соц. часть | live-лента дропов, онлайн, топ игроков |
| Честность | server/client seed, nonce, смена сида с раскрытием, форма проверки |
| Вход | Telegram (через бота), ник+пароль, гостевой режим |
| Админка | статистика, пользователи (баланс, бан, права, транзакции, инвентарь), кейсы (содержимое, веса, RTP), предметы и цены, промокоды, JSON-импорт |

## Стек

- `apps/web` — Next.js 15 + React 19
- `apps/api` — Fastify 5 + Socket.IO + Prisma (SQLite)
- `packages/shared` — типы, экономика (шансы апгрейда/контрактов), provably fair
- `tools/gen_scenes.py` — генерация иллюстраций для обложек кейсов локальной моделью SD-Turbo

## Локальный запуск

Нужно: Node.js 22 и pnpm (`corepack enable`).

```bash
pnpm install
cp apps/api/.env.example apps/api/.env      # при желании впишите токен Telegram-бота
pnpm --filter api db:push
pnpm --filter api db:seed                    # скачает скины CS2 и создаст кейсы, ботов, промокоды, админа
pnpm dev                                     # web: http://localhost:3000, api: http://localhost:4000
```

Админ для локальной разработки создаётся из `ADMIN_NICKNAME` / `ADMIN_PASSWORD` в `apps/api/.env`.
Перезалить каталог поверх существующего: `pnpm --filter api db:seed:force` (сбросит правки кейсов из админки).
Без интернета: `CATALOG=generated pnpm --filter api db:seed:force` — выдуманный каталог.

Тесты: `pnpm test` (API-сценарии: открытие, продажа, апгрейд, контракт, батл с ботами, доступ в админку).

## Вход через Telegram

1. Создайте бота в [@BotFather](https://t.me/BotFather) → получите токен.
2. Впишите в `apps/api/.env`: `TELEGRAM_BOT_TOKEN=...` и `TELEGRAM_BOT_USERNAME=имя_бота` (без @).
3. На сайте «Войти» → «Войти через Telegram» → в боте нажать **Start** — вкладка войдёт сама.

Работает и локально, и на сервере: бот читает обновления сам (long polling), домен и вебхук не нужны.

## Деплой на свой сервер (играть с друзьями)

На сервере нужен Docker с compose.

```bash
git clone https://github.com/OneJagermeisterPlease/casebattle.git && cd casebattle
cp apps/api/.env.example apps/api/.env       # задайте JWT_SECRET, ADMIN_*, TELEGRAM_*
SITE_ADDRESS=:80 docker compose up -d --build
```

- Сайт откроется по `http://IP-сервера`. С доменом: `SITE_ADDRESS=casino.example.com` — Caddy сам выпустит HTTPS.
- Если сервер доступен только внутри VPN — используйте его VPN-адрес, друзьям нужен доступ к VPN.
- База (SQLite) лежит в docker-томе `data` и переживает перезапуски. Бэкап: `docker compose cp api:/data/casebattle.db ./backup.db`.
- Обновление: `git pull && docker compose up -d --build`.

Все друзья входят через Telegram, видят друг друга в ленте дропов и лобби батлов, могут создавать батлы и занимать места — прокрутка у всех синхронная в реальном времени.
